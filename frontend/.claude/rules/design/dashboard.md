# Design — Dashboard (운영 관리 화면)

매니저용 운영 관리 화면 전용 규칙이다. 대시보드는 **조회·비교·재고 확인·판매 분석**이 중심이며, POS와 달리 시간 압박이 낮고 마우스+키보드로 조작한다. POS와 동일한 컴포넌트 크기·밀도를 강제하지 않는다.

## 확정된 화면

| Screen ID | 화면 |
|---|---|
| S-06 | 상품 마스터 |
| S-07 | 판매 통계 |
| S-11 | 재고 관리 |
| S-12 | 재고 알림 |

> 운영 현황(KPI) 대시보드 화면과 매니저 전용 판매 내역 화면은 `rules/ux.md` §10에 따라 **아직 확정되지 않았다(보류)**. 이 문서는 위 4개 확정 화면만 다루며, 두 미확정 화면의 레이아웃·컴포넌트를 임의로 설계하지 않는다.

## Dashboard Layout

| 항목 | 값 |
|---|---|
| 기기 | 웹 브라우저 |
| 기준 캔버스 | 1440×900 |
| 입력 | 마우스 + 키보드 |
| 최소 터치 타깃 | 40px |
| 목록 행 높이 | 표준 |
| 시간 압박 | 낮음 |
| 스크롤 | 허용 |

관리 화면 간 이동은 사이드바로 자유롭다. 직원 POS·고객 화면에는 관리 화면 진입 경로를 두지 않는다 — 매니저 전용 진입이다.

## Sidebar

좌측 고정. 정렬 순서는 사용 빈도가 아니라 **판단 → 조치** 순서를 따른다:

1. 재고 알림 (S-12)
2. 재고 관리 (S-11)
3. 판매 통계 (S-07)
4. 상품 마스터 (S-06)

매니저가 관리 화면을 여는 계기는 대부분 "무언가 부족하다"는 인지이기 때문에, 조치가 필요한 항목을 먼저 보여주는 순서를 유지한다.

## Topbar

- 재고 관리 화면(S-11)에는 POS와의 연결 상태를 표시한다. 연결이 끊긴 상태에서는 재고 수치가 최신이 아니므로 마지막 갱신 시각을 함께 병기한다.
- 연결이 끊겨도 상품 마스터(S-06) 등록·수정 같은 독립적인 조작은 차단하지 않는다.

## KPI

운영 현황(KPI) 대시보드 화면은 **보류 상태**다(`rules/ux.md` §9~10). KPI 카드·요약 지표의 구성은 아직 정의하지 않는다. 필요하다고 판단되면 임의로 만들지 않고 먼저 확인한다.

## Chart

확정된 화면(S-06, S-07, S-11, S-12) 중 소스 문서에서 명시적으로 차트를 요구하는 화면은 없다. S-07 판매 통계는 **표 기반** 비교 화면으로 정의되어 있다(§Data Table 참고). 차트 컴포넌트는 아직 정의하지 않는다.

## Data Table

- 관리 화면의 기본 형태는 **표**다. 카드 나열은 쓰지 않는다 — 매니저의 작업은 품목 간·기간 간 비교이고, 카드는 비교에 불리하다.
- **조치가 필요한 항목이 위로 온다** (예: 매진 임박/매진 품목을 정렬 상단에).
- 상태는 배지 + 수치를 병기한다 — 배지만으로 전달하지 않는다.
- 스크롤을 허용하는 대신, 상위 항목 노출 + "외 M개" 축약 형태를 고려할 수 있다(구체적 노출 개수는 화면별로 확정 필요).

## Filter

필터는 표 상단에 고정한다.

## Search

상품명 검색은 카탈로그성 화면(상품 마스터, 재고 관리)에 공통으로 필요하다.

## Period Selector

기간 선택은 표 상단 우측에 두고, 오늘 / 1주일 / 1개월 단위를 기본으로 한다. 판매 통계(S-07)에서 기간을 바꿔가며 비교하는 데 쓰인다.

## Status Badge

상태는 배지 + 텍스트 + 수치를 함께 표시한다 — 배지 단독으로 전달하지 않는다(foundation 상태 표현 원칙과 동일).

## Inventory Meter

- 재고 상태는 **정상 / 매진 임박 / 매진** 3단계로 표현하고, 색 + 상태 텍스트 + 수치를 함께 표시한다.
- 재고 수치는 실물과 차이가 날 수 있는 추정치다 — 화면 문구는 "재고 12개"가 아니라 "**추정 12개**"로 쓴다. 자동 발주로 이어지지 않는 참고 정보임을 함께 명시한다.
- 기준선(매진 임박 판정 기준)은 상품별로 설정되는 값이며, 화면은 그 결과(상태)만 표시한다.

## Alert

- 사이드바 재고 알림(S-12) 항목에 미읽음 건수를 배지로 표시한다 — 매니저가 관리 화면을 상시 보지 않으므로 사이드바가 유일한 통지 지점이다.
- 알림이 없는 빈 상태를 오류처럼 표시하지 않는다.

## Modal

foundation의 Modal 기본 원칙을 그대로 따른다. 대시보드에 파괴적 조작(삭제 등)이 필요하면 확인 단계를 거친다.

## 데이터 밀도

시간 압박이 낮고 마우스 입력이므로 POS보다 정보 밀도를 높게 잡을 수 있다.

## 정렬 및 조치 우선순위

정렬 기준은 항상 "무엇이 조치가 필요한가"를 먼저 보여주는 방향이다(예: 재고 알림 상단 배치, 매진 임박 품목 우선 노출).

## 매진 임박 / 매진 표현

| 상태 | 표시 |
|---|---|
| 정상 | 기본 |
| 매진 임박 | 색 + "매진 임박" 텍스트 + 수치 |
| 매진 | 색 + "매진" 텍스트 + 수치 |

## 비교 중심 UI 원칙

판매 통계(S-07)는 기간을 바꿔가며 비교하는 화면이다. 기간 선택 UI와 표 형태를 우선하고, 단일 시점 스냅샷보다 기간 대비 변화를 보여주는 구성을 우선한다.
